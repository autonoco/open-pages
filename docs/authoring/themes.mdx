A theme is a reusable visual identity for your pages. Because every component under `ui/` and every token class reads the shadcn CSS variables, a theme is mostly a set of variable values: swap them and the whole page restyles, components included.

## The bundle

A theme is three files under `themes/` sharing one stem:

```
themes/
  midnight-saas.md         # direction for the agent
  midnight-saas.css        # token overrides the runtime applies
  midnight-saas.demo.tsx   # a demo page composed from ui/*
```

**`<id>.css`** holds `:root { … }` and `.dark { … }` blocks overriding the shadcn tokens (`--background`, `--foreground`, `--primary`, `--muted`, `--border`, `--radius`, `--chart-1..5`, the `--sidebar-*` set), optionally a Google Fonts `@import` and `--font-sans` / `--font-heading` values. No Tailwind import and no `@theme` block: `styles/globals.css` already maps the variables to utilities.

```css themes/midnight-saas.css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap');

:root {
  --font-sans: 'Inter', ui-sans-serif, system-ui, sans-serif;
  --background: oklch(0.13 0.02 265);
  --foreground: oklch(0.97 0 0);
  --primary: oklch(0.78 0.16 160);
  --primary-foreground: oklch(0.15 0.02 160);
  --muted-foreground: oklch(0.7 0.01 265);
  --border: oklch(1 0 0 / 12%);
  --radius: 0.75rem;
}
```

**`<id>.md`** is what the agent reads before authoring: the aesthetic, fonts, a palette table mapping each token to its value, and notes on which components and layouts the theme favors.

**`<id>.demo.tsx`** is a page module (one default-exported component) composed from `@/ui/*`, so the workspace's **Themes** panel shows the tokens on real parts. The runtime injects `<id>.css` into the demo automatically.

## Applying a theme

A page opts in with `meta.theme`:

```tsx
export const meta: PageMeta = {
  title: 'Meridian — Launch',
  theme: 'midnight-saas',
  createdAt: '2026-08-28T12:00:00.000Z',
};
```

The runtime injects `themes/midnight-saas.css` into that page's frame in the preview and into its [export](/export). Pages without `meta.theme` use the neutral defaults in `styles/globals.css`. Because the theme is a stylesheet, not copied source, editing `<id>.css` restyles every page that uses it.

## Authoring one

- Ask your agent to "create a theme called X from these images" (or from a brand guide, a description, or an existing page). The bundled **create-theme** skill writes all three files.
- Tune colors, radius, and fonts at [ui.shadcn.com/create](https://ui.shadcn.com/create) and hand the preset code to the agent, or apply it yourself: `npx shadcn@latest apply <code> --only theme,font`. The agent then lifts the resulting variables into `themes/<id>.css`.
- The **create-page** skill lists registered themes as a picker when scaffolding a new page and sets `meta.theme` for you.

The workspace's **Themes** panel previews every demo live, in the same frame the pages use, and lists the pages built from each theme.
