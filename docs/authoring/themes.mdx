A theme is a reusable visual identity for your pages: palette, typography, layout, and paste-ready fixed components like a nav, hero, section wrapper, and footer. Themes let every page a team (or its agent) produces share one look.

## The bundle

A theme is two paired files under `themes/`, sharing the same stem so the runtime can pair them:

```
themes/
  midnight-saas.md         # the theme definition
  midnight-saas.demo.tsx   # a runnable demo page of the theme
```

**`<id>.md`** is the definition the agent reads: a palette table (background, text, muted, accent, rule roles as Tailwind utilities and hex), typography (fonts and type scale), layout (container widths, spacing rhythm, breakpoints), fixed components as paste-ready JSX with `className`, and an aesthetic paragraph that commits to one direction.

**`<id>.demo.tsx`** is a runnable page with the same module shape as `pages/<id>/index.tsx`: one default-exported component. It inlines the same fixed components the markdown defines, so what the demo shows matches what gets pasted into real pages.

The workspace's **Themes** panel previews every demo live, in the same frame the pages use, and lists the pages built from each theme.

## How themes get used

- The bundled **create-theme** skill authors the bundle. It can derive a theme from screenshots or brand images, a free-text description, or an existing page whose look you want to lift out and reuse. See [For agents](/for-agents).
- The **create-page** skill lists registered themes as a picker option when scaffolding a new page, then copies the theme's palette, utilities, and fixed components into the page's source.
- A page built from a theme sets `meta.theme` to the theme id (matching the `<id>.md` basename). When editing such a page, the theme file is authoritative over the framework's defaults.

The theme markdown is authoring-time direction, not a runtime import. Its styles are copied into each page's source, so a page stays self-contained and a theme change never silently restyles shipped pages.

## Writing one

Ask your agent to "create a theme called X from these images" (or from an existing page), and the create-theme skill handles structure, pairing, and self-review. If you write one by hand, match an existing bundle's section order: Palette, Typography, Layout, Fixed components, Aesthetic, Example usage. The fixed components must be valid React JSX with `className` and no external imports, because they get pasted verbatim into pages. See [Styling](/authoring/styling) for the conventions.
